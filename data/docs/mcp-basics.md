# MCP（Model Context Protocol）基础

MCP 是让 AI 应用以统一方式连接外部工具与数据的开放协议，常被类比为「AI 的 USB-C」。它解决的是 N×M 集成问题：没有统一协议时，每个模型客户端对接每个工具都要单独写连接器；有 MCP 后，工具实现一次服务器，任何支持 MCP 的客户端都能用。

## 架构

- **Host**：AI 应用本身（如 Claude Desktop、Cursor、IDE 插件），负责发起会话。
- **Client**：Host 内部与某个 Server 保持一对一连接的组件。
- **Server**：暴露能力的一端，可以是本地进程，也可以是远程服务。

## 三类原语

1. **Tools（工具）**：可被模型调用的函数，带 JSON Schema 描述参数，属于「模型决定调用」的能力。
2. **Resources（资源）**：可被读取的数据，如文件、数据库记录，属于「应用决定注入上下文」的能力。
3. **Prompts（提示模板）**：预置的提示词模板，供用户显式选择。

## 传输方式

本地常用 stdio（标准输入输出），远程常用 HTTP + SSE 或 streamable HTTP。协议基于 JSON-RPC 2.0。

## 安全注意

工具调用意味着真实副作用（写文件、发请求、改数据库）。生产环境要做权限控制、最小授权、调用审计，并对高风险操作加入人工确认。MCP Server 不应默认信任客户端传入的参数。
